# AMI

This section covers tooling and workflows that maintainers use to keep the
CAPA AMI catalogue current.

- [Publishing AMIs](./publishing-amis.md) — build and release new AMIs for a
  given Kubernetes version.
- [Detect Kubernetes Release Versions](./detect-k8s-release.md) — query the
  upstream `kubernetes/kubernetes` repository for the stable release
  versions that the CAPA AMI publication policy should track.
